# Minha coleção de projetos

Galeria PWA e projetos HTML associados. O repositório não inclui executáveis.

## Publicar no GitHub Pages

1. Envia estes arquivos para a branch `main` de um repositório público.
2. No GitHub, abre **Settings → Pages** e escolhe **GitHub Actions** como origem.
3. O workflow publica o site automaticamente. O endereço aparece em **Settings → Pages**.
4. No Android, abre esse endereço HTTPS no Chrome e escolhe **Instalar app** ou **Adicionar ao ecrã inicial**.

O código-fonte também pode ser descarregado pelo botão **Code → Download ZIP** do repositório.

## Conteúdo

- `index.html`, `manifest.webmanifest`, `sw.js` e `icons/`: aplicação PWA.
- As pastas com ficheiros HTML: páginas abertas pelos cartões da galeria.

Os projetos adicionados manualmente são guardados no armazenamento local do navegador e não são enviados para o repositório.
